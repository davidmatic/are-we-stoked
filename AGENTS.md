# are-we-stoked

Pushing to `main` deploys the live site (GitHub Pages, davidmatic.github.io/are-we-stoked); Pages only works while the repo stays public.

## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues on davidmatic/are-we-stoked (via `gh`). See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary (needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
